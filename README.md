# Pawlish 宠物洗护店门户网站

Pawlish 是一个基于 Next.js 构建的宠物店单页门户网站，面向宠物洗护与门店展示场景。项目包含品牌头图、服务介绍、会员权益、预约流程、顾客评价、门店环境展示与联系方式等模块。

## 技术栈

- Next.js 16
- React 19
- TypeScript

## 页面内容

- 顶部导航与品牌信息
- 宠物洗护门店主视觉区
- 服务项目展示
- 会员权益介绍
- 到店预约流程
- 顾客评价
- 门店环境轮播
- 联系方式与地址信息

## 本地启动

```bash
npm install
npm run dev
```

默认启动后可访问 `http://localhost:3000`。

## 常用命令

```bash
npm run dev
npm run build
npm run start
```

## 项目结构

```text
app/          Next.js App Router 页面与全局样式
components/   页面模块组件
public/assets/ 页面使用的静态图片资源
assets/       原始设计资源
```

## 项目说明

- 当前仓库主体是宠物店官网项目，不是个人助理系统。
- 根目录的 `index.html` 可作为静态原型参考。
- 页面标题与描述已配置为 `Pawlish 宠物洗护店`。
